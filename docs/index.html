좌표와 영역은 고정하고 오차 ε만 바꾸어 판별 결과를 비교합니다.

실험 최대 오차 ε 거리 d 오차 범위 반지름 가능한 중심 거리 판별 결과
수학적 판별 원리

영역의 중심을 C(a, b), 반지름을 r, 측정 위치를 P(x, y), 측정 오차의 최대값을 ε이라고 합니다. 원의 내부는 (x-a)² + (y-b)² ≤ r²로 나타냅니다.

  • 반드시 내부: d + ε ≤ r — 가능한 모든 실제 위치가 원 안에 있습니다.
  • 반드시 외부: d - ε > r — 가능한 모든 실제 위치가 원 밖에 있습니다.
  • 판단 불확실: 위 두 조건 모두 성립하지 않습니다.

ε은 실제 위치와 측정 위치 사이 거리의 최대값이라는 가정입니다. 경계에서 d + ε = r이면 반드시 내부이며, d - ε = r이면 반드시 외부 조건의 엄격 부등호를 만족하지 않아 판단 불확실입니다.
