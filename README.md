# GPS 위치 오차 시뮬레이터

GPS 측정 위치의 오차 범위를 시각화하고 원형 영역의 내부·외부 여부를 판별하는 웹 앱입니다.

[GitHub Pages에서 앱 열기](https://blape0123.github.io/dream_project_v.1/)

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 `docs/`의 정적 웹 앱을 자동으로 배포합니다.
처음 배포하기 전에 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하세요.
로컬 실행과 배포 방법은 [프로젝트 안내](project/README.md)를 참고하세요.
